## 七、常见问题

**IP 是原生台湾 IP 吗？**
分情况。低价 Lite 类产品是机房 IP，归属地显示在台湾，但对严格判定住宅 IP 的平台可能无效。HiNet 家宽系列是动态原生 IP，纯净度更好。WePC 的台湾线里，商品名写“原生 IPv4”和写“双 ISP 住宅 IP”的是两种东西，看清楚再付钱。

**流量用完会停机吗？**
不会，基本都是限速。1Mbps 或 5Mbps 取决于商家和套餐，速度会慢到影响正常使用，但机器还在。

**能装 Docker、WireGuard 吗？**
KVM 虚拟化的机器可以，ByteVirt 的 Lite 系列明确支持。OpenVZ/LXC 架构的限制多，下单前确认虚拟化类型。

**开通要多久？**
ByteVirt 一般是 12–24 小时，特价款可能更久。WePC 有测评记录是付款后 5–10 分钟开通，登录信息发到邮箱。

**能不能拿来做代理？**
先看条款。遠振的用户条款明文禁止“公开的 Web Proxy 服务”，也禁止游戏私服、黑帽 SEO 站点和用 CGI 写的论坛聊天室。WePC 有第三方测评提到其条款不接受 Shadowsocks 协议。这类用途被停机的风险由你自己承担，别默认“VPS 什么都能干”。
